Example Request

You can use our API in your preferred programming language. Here is an example request in curl. We currently have a Python SDK , and are working on SDKs for other languages. 

                                            
                                            curl -L \
                                            -X POST \
                                            -H 'Authorization: Bearer <token>' \
                                            -H 'Content-Type: application/json' \
                                            'https://api.colivara.com/v1/search/' \
                                            -d '{"query": "What is 1 + 1?"}'
